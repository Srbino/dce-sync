Where do I find my token?

DiscordChatExporter uses your Discord Authorization token, not a browser cookie.

  1. Open Discord in your browser and sign in to the account you want to archive.
  2. Open Developer Tools (⌘⌥I on macOS, Ctrl+Shift+I on Windows/Linux), then the Network tab.
  3. Switch to a channel. Select a request to discord.com/api.
  4. Under Request Headers, copy the value of Authorization and paste it above.
  5. Save it, then use Test connection to check accessible servers.

Keep the token private, just like a password. A bot token can also be used; its access depends on server permissions and the Message Content intent.
